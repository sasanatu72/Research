# タンパク質言語モデル埋め込みベクトルが内包するアミノ酸指標の情報

## 研究概要
本研究ではアライメントに依らない系統樹作成手法として、タンパク質言語モデルの使用を検討する。学習済みのタンパク質言語モデルにタンパク質配列を入力し、得られた埋め込みベクトルの各次元とアミノ酸指標の相関係数を計算する。相関係数の絶対値が大きい順にアミノ酸指標を増やしていき系統樹を作成し、RF 距離によって評価する。使用したアミノ酸指標の数と RF 距離の変化から、各次元が内包するアミノ酸指標の情報を明らかにする。

## 実行手順
1. get_embedding.py\
配列データからesmライブラリを使用してタンパク質言語モデルの埋め込みベクトルを取得する。36層のうち最終層から取得している。
2. amino_score.py\
埋め込みベクトルの各次元に対して各アミノ酸に対して一つの値を持つように各アミノ酸ごとに平均する。アミノ酸指標のデータ形式と統一することで相関係数の計算が可能になる。
3. get_aaindex.py, exclusion_NA.py, exclusion_out.py\
aaindexライブラリからアミノ酸指標を取得、欠損値を持つものを除外、外れ値を持つものを除外する。
4. corr_aaindex.py\
タンパク質言語モデルの各次元とアミノ酸指標との相関係数の絶対値の計算。相関係数の絶対値が大きい順にソートしておく。各アミノ酸に一つの値が割り当てられている形式(20×1)で相関係数(pearson)を求める。
5. incremental_aaindex.py
    1. graph_aaindex.py\
    アミノ酸指標をアミノ酸配列の各アミノ酸に割り当て、アミノ酸配列順につなげる。グラフィカル表示。
    2. mean_graph_aaindex.py\
    グラフィカル表示したアミノ酸配列の重心を求める。系統樹作成における特徴量となる。後に必要になってくるデータの作成。\
    ※本研究では多くの系統樹を作成することから実行時間が膨大になる可能性があるため、特徴量を重心という単純で高速な計算手法で実行時間の削減を実現する。
    3. distance_matrix.py (実行はしない)\
    グラフィカル表示したアミノ酸指標から抽出した特徴量(重心)から距離行列を作成する。距離はコサイン類似度とユークリッド距離の2通りである。
    4. make_tree.py (実行はしない)\
    距離行列から系統樹を作成し、Clustal Omegaで作成された系統樹とのRF距離を計算する。系統樹作成手法はNJ法、UPGMA法の2通りである。
    5. incremental_aaindex.py\
    埋め込みベクトルの各次元(2560次元)において、相関が高いアミノ酸指標を順に1つずつ増やしていき系統樹を作成する。RF距離0の系統樹が作成されるとその次元はRF距離0を達成した次元となる。
6. analyze.py\
作成された系統樹の中でRF距離0のものがあった次元が何次元あったかをカウントする。また、RF距離0を安定して達成したものをカウントする。RF距離0を安定して達成したとき何個のアミノ酸指標を使用しているのかをヒストグラムで表示。

## その他

### データについて

- 使用した配列データは `data/` フォルダに格納されており、ミトコンドリア遺伝子ND5(NADH dehydrogenase subunit5) のアミノ酸配列である。9種類の哺乳類を生物種として採用している。このデータを使用している先行研究が多いためこちらを使用する。
- 系統樹の正解データは Clustal Omega により生成する。

### 実行上の注意

- incremental_aaindex.py は全2560次元に対して処理を行うため非常に時間がかかる
- get_embedding.py はタンパク質言語モデルに配列データを入力するため多くの時間を要するが、本研究のデータ量では致命的な実行時間の大きさにはならないためCPUで実行している。

### 補足

本研究はアライメントフリーな系統解析手法の可能性を検討するものである。
